# Kasper 👻

**Kasper** — неофициальный клиент Telegram для iPhone на основе открытого исходного кода
[Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS). Работает через официальный API
и серверы Telegram, но со своим названием, логотипом, приветственным экраном и разделом **Kasper** в настройках.

<img src="branding/kasper-icon-preview.png" width="160" alt="Иконка Kasper">

> Kasper не связан с Telegram FZ-LLC. Проект для личного использования, не публикуется в App Store.

| 👻 Призрак: прочтение | Не отправляются отметки о прочтении в личных чатах, группах, темах и комментариях | Сообщения помечаются прочитанными только у вас; счётчики могут вернуться после переустановки |
| 👻 Призрак: «печатает…» | Не отправляется статус набора текста и записи голосового | — |

| 🗑 Удалённые сообщения | Сообщение, удалённое собеседником, остаётся в чате с пометкой «🗑 Удалено» вместе с текстом и уже загруженными файлами | Личные чаты по умолчанию, группы — по переключателю. Kasper ловит удаление, только когда получает обновление от Telegram (то есть был запущен или пришло уведомление). Сообщения, удалённые вами, исчезают как обычно |
| 🎤 Голос в голосовых | 8 голосов: женский, мужской, детский, робот, пиксель, эхо, монстр, старик. Запись обрабатывается на телефоне до отправки | — |

Kasper сам подбирает каждому голосу подходящий голос ElevenLabs; нужен свой API-ключ | Только голосовые сообщения. | 🆔 ID в профиле | На странице профиля, канала и группы Kasper показывает ID — нажатие копирует его | — |

Чего клиент сделать не может, в разделах честно помечено «Недоступно» с причиной: размер и форма
аватарок и пузырей, сила размытия стекла, пароль на отдельный чат, свои иконки вкладок, кроссфейд,
межстрочный интервал, замена иконок самого Telegram.

Раздел **Kasper** собран из раскрывающихся блоков: нажатие на строку плавно открывает её настройки, стрелка поворачивается. Переключатель на самой строке включает весь блок сразу.
Счётчик «Поймано удалённых» показывает, сколько удалённых сообщений сохранено.

ID и дата создания встроены и работают всегда — отдельного переключателя для них нет.

Откуда берётся дата: поля «дата регистрации» в API Telegram не существует, но ID выдаются по возрастанию.
Kasper держит таблицу известных пар «ID — дата» (открытый набор
[Jobians/telegram-id-age](https://github.com/Jobians/telegram-id-age), наблюдения с августа 2013 по ноябрь 2025)
и считает дату между ближайшими точками прямо на телефоне — никакие запросы никуда не отправляются.
У каждого отрезка таблицы своя погрешность, поэтому Kasper показывает ровно столько, сколько знает:
«≈ март 2022», «≈ декабрь 2022 ± 5 месяцев» или «между 2017 и 2019». Для аккаунтов новее таблицы
дата досчитывается по скорости выдачи ID и помечается «точность ниже».
У каналов и групп ID свой, отдельный от пользовательского, поэтому дата создания для них не показывается.

⚠️ Функции «Призрака» меняют стандартное поведение клиента. Telegram может ограничивать аккаунты за
нестандартное поведение сторонних клиентов — используйте на свой риск.

Официальный способ скрыть время захода — **Настройки → Конфиденциальность → Время захода**.

## Как это устроено

В репозитории лежит только **патч** (`patches/kasper.patch`) — изменения Kasper поверх Telegram-iOS `release-12.9.2`.
GitHub Actions на бесплатном Mac-сервере скачивает официальный код, накладывает патч и собирает `Kasper.ipa`.

Изменённые места:
- `Telegram/BUILD` — название «Kasper», сборка без расширений
- `Telegram/Telegram-iOS/Telegram.icon` — иконка
- `Telegram/Telegram-iOS/en.lproj/Localizable.strings` — тексты приветствия
- `submodules/RMIntro` — логотип на приветственном экране
- `submodules/TelegramCore/Sources/Kasper` — хранилище настроек Kasper
- `submodules/TelegramCore/Sources/State/*`, `.../TelegramEngine/Messages/*` — «Призрак» и удалённые сообщения
- `submodules/SettingsUI/Sources/Kasper` — экран Kasper
- `submodules/TelegramUI/Sources/Kasper` — изменение голоса, ElevenLabs для голосовых, надпись на скриншотах
- `submodules/TelegramCore/Sources/Kasper/KasperElevenLabs.swift` — запросы к ElevenLabs (библиотека голосов, Voice Changer)
- `submodules/TgVoipWebrtc/Sources/KasperCallVoice.h` — изменение голоса в звонках
- `submodules/TelegramCore/Sources/Kasper/KasperAccountAge.swift` — таблица «ID → дата» и оценка даты создания
- `submodules/TelegramUI/Components/PeerInfo/PeerInfoScreen` — пункт Kasper в настройках, ID и дата создания в профиле
- `submodules/TelegramUI/Components/Chat/ChatAvatarNavigationNode` — точка «в сети»
- `submodules/TelegramUI/Sources/TelegramRootController.swift`, `SharedAccountContext.swift` — вкладка «Профиль», стекло
- `submodules/TelegramCore/Sources/SyncCore/SyncCore_TelegramMediaFile.swift` — WAV как треки
- `submodules/SaveToCameraRoll` — надпись на кружках

## Сборка

1. **Получите api_id.** Зайдите на [my.telegram.org](https://my.telegram.org) → *API development tools*,
   создайте приложение (название — Kasper, платформа — iOS). Скопируйте `api_id` и `api_hash`.
2. **Добавьте секреты** в репозиторий: *Settings → Secrets and variables → Actions → New repository secret*:
   - `API_ID` — число api_id
   - `API_HASH` — строка api_hash
3. **Запустите сборку:** вкладка *Actions → Build Kasper IPA → Run workflow*.
   Первая сборка идёт 2–4 часа, следующие быстрее благодаря кэшу.
4. **Скачайте IPA:** вкладка *Releases* → `Kasper.ipa`.

Репозиторий должен быть **публичным**: так Mac-серверы GitHub Actions бесплатны (и этого требует лицензия GPL Telegram).

Если сборка упала — откройте запуск в *Actions*, на странице *Summary* будут строки с ошибками.

## ✨ Реалистичные голоса

Обычно Kasper меняет голос прямо на телефоне: быстро и без интернета, но звучит синтетически.
Переключатель **✨ Реалистичные голоса** оставляет тот же список голосов, но озвучивает их
через ElevenLabs Voice Changer — получается живой голос с вашими словами и интонациями.

1. Зарегистрируйтесь на [elevenlabs.io](https://elevenlabs.io). Бесплатного тарифа хватает примерно на 10 минут голосовых в месяц.
2. *Developers → API Keys → Create API Key*. В правах ключа включите **Voices** и **Speech to Speech** (или оставьте полный доступ).
3. В Kasper: *Настройки → Kasper → 🎤 Смена голоса* → включите **✨ Реалистичные голоса** и вставьте ключ.
   Kasper сам подберёт каждому голосу подходящий голос ElevenLabs и покажет его имя рядом: «👩 Женский · Sarah».
   Кнопка «Подобрать голоса заново» пригодится, если вы добавили свои голоса в *My Voices*.
4. Запишите голосовое как обычно. После остановки Kasper отправит запись в ElevenLabs и вернёт её уже переозвученной.

Робот, Пиксель, Эхо и Монстр — это голос ElevenLabs плюс эффект Kasper поверх.

Чего ждать:
- Отправка задерживается на несколько секунд: запись успевает съездить в ElevenLabs и обратно.
  Ожидание ограничено (8–20 секунд в зависимости от длины) — дальше Kasper не ждёт.
- Если ElevenLabs не ответил, кончились кредиты или нет интернета, уходит запись с обычным
  эффектом Kasper. Настоящий голос не отправляется ни при какой ошибке, а причина
  появляется под разделом голоса.
- В звонках и на кружках реалистичные голоса не работают: там нужна обработка в реальном
  времени, и Kasper меняет голос на телефоне.

Ключ хранится только на телефоне и уходит только на `api.elevenlabs.io`.

## Установка на iPhone

IPA не подписан. Подписать и установить его бесплатно можно так:

- **Sideloadly** (Windows или Mac, бесплатный Apple ID): подключите iPhone кабелем, перетащите `Kasper.ipa`,
  в *Advanced options* задайте свой *Bundle ID* (например `com.вашеимя.kasper`), нажмите *Start*.
  Затем на iPhone: *Настройки → Основные → VPN и управление устройством* → доверять профилю, и включите
  *Режим разработчика* (*Настройки → Конфиденциальность и безопасность*).
  С бесплатным Apple ID приложение нужно переподписывать **каждые 7 дней**.
- **SideStore** — после первоначальной настройки с компьютера умеет переподписывать приложение прямо на iPhone.
- **Платный аккаунт разработчика** ($99/год) — подпись на год.

Push-уведомления в сборке с бесплатной подписью не работают — это ограничение Apple.
